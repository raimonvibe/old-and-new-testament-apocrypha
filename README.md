# Old and New Testament Apocrypha Reader

A modern web reader for deuterocanonical, Old Testament pseudepigrapha, and New Testament apocrypha — modeled after [bible-old-and-new-testament](https://github.com/raimonvibe/bible-old-and-new-testament).

**Text sources:** [sacred-texts.com](https://www.sacred-texts.com/chr/apo/index.htm)
