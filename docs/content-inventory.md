# Apocrypha Content Inventory (sacred-texts.com)

Research for the **Old and New Testament Apocrypha** reader website.  
Source: [Internet Sacred Text Archive](https://www.sacred-texts.com/chr/apo/index.htm)

---

## How sacred-texts organizes apocrypha

| Layer | Description | Base URL |
|-------|-------------|----------|
| **Deuterocanonical** | Books in some Bibles, excluded from others | [/bib/apo/](https://www.sacred-texts.com/bib/apo/index.htm) |
| **OT pseudepigrapha** | Non-canonical Old Testament writings | [/bib/fbe/](https://www.sacred-texts.com/bib/fbe/index.htm) + standalone texts |
| **NT apocrypha** | Early Christian gospels, acts, epistles | [/bib/lbob/](https://www.sacred-texts.com/bib/lbob/index.htm) + standalone texts |
| **Related** | Scholarly / derivative collections | [/chr/apo/](https://www.sacred-texts.com/chr/apo/index.htm), [/bib/coj/](https://www.sacred-texts.com/bib/coj/index.htm) |

## Overlaps to handle

- **Laodiceans** — in both `/bib/apo/lao.htm` and LBOB
- **Adam & Eve** — FBE, Vita Adae, and Slavonic versions
- **Enoch** — Charles and Laurence translations
- **Verse format** — deuterocanonical uses chapters; some texts use odes, sayings, or prose only

  }
}

```json
{
  "id": "TOB.1",
  "number": "1",
  "reference": "Tobit 1",
  "content": "     [1] First verse text..."
}
```
